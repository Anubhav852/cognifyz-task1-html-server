# Task 1: HTML Structure and Basic Server Interaction

##  Objective
Introduce the concept of server-side rendering and basic form submissions using Node.js and Express.

## Tech Stack
- **Frontend:** HTML, EJS (Embedded JavaScript Templates)
- **Backend:** Node.js, Express.js
- **Styling:** CSS3

##  Project Structure
```
level1-task1/
├── public/
│   └── style.css
├── views/
│   ├── index.ejs
│   └── result.ejs
├── .gitignore
├── package.json
├── server.js
└── README.md
```
##  Setup & Installation

1. Clone the repository
```bash
git clone https://github.com/Anubhav852/cognifyz-task1-html-server.git
cd cognifyz-task1-html-server/level1-task1
```

2. Install dependencies
```bash
npm install
```

3. Start the server
```bash
npm start
```

4. Open your browser and visit

http://localhost:3000

##  Features
- HTML form with fields for Name, Email, Phone and Message
- Express server handling GET and POST routes
- Server-side rendering using EJS templates
- Dynamic result page displaying submitted form data
- Clean and responsive CSS styling

##  How It Works
1. User visits `http://localhost:3000`
2. Fills in the registration form
3. Submits the form via POST request
4. Server processes the data and renders the result page dynamically using EJS
